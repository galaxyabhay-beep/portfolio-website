# Abhay Kumar Sinha - Personal Portfolio Website

Personal portfolio website for **Abhay Kumar Sinha**, Director at SILKROAD TOUR (I) PVT. LTD. and founder of the travel platform *Amazingly Abhay*.

## Overview

This website highlights:
- **Professional Background & Leadership:** Over 20 years in Indian inbound tourism and Buddhist pilgrimage circuits.
- **Published Travel Essays & Philosophy:** Features articles from [Amazingly Abhay](https://amazinglyabhay.com/) advocating mindful, experiential travel.
- **Competencies & Skills:** Inbound tour logistics, international client relations (Far-East Asia), travel writing, and Generative AI workflows.
- **Direct Contact:** Quick links to LinkedIn, GitHub, personal website, and a direct inquiry form.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide Icons & Custom SVG Marks

## Getting Started

To run this project locally:

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
